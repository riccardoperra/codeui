# Agent rules

## Design

Before you build or change anything visual (a component, a story, a docs demo, a token), read [`packages/kit/DESIGN.md`](packages/kit/DESIGN.md). It is the Inkstone specification and ships with `@codeui/kit`.

- Follow its rules and run its review checklist (§12) on your change.
- When a change alters a rule, update `packages/kit/DESIGN.md` and the matching page in `apps/docs/content/docs/design/` in the same pull request.
- When the specification and the code disagree, say so in the pull request. Do not copy the drift into new code.
