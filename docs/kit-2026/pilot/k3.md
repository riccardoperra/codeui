# K3 pilot: CodeImage overlays on the kit parts

Goal. The roadmap lets the styled-parts pattern spread past Dialog and Popover only if CodeImage's direct Kobalte dialog and popover imports reach zero. This pilot rewrote five CodeImage callers against the K3 kit and counted those imports.

Method.

- Source. CodeImage `origin/main` at `dfdeda77`, read with `git show` and `git archive` into a scratch directory outside every repository. Nothing was written to CodeImage.
- Count. The `IMPORT_RE` and `SIDE_EFFECT_RE` expressions of `phase-0/tools/census.mjs`, applied to each file before and after the rewrite. A file counts one per import statement whose module is `@kobalte/core/dialog` or `@kobalte/core/popover`.
- Typecheck. `tsc --noEmit` on the exported CodeImage app with `@codeui/kit`, `@codeui/kit/dialog` and `@codeui/kit/popover` mapped to the K3 package `.d.ts` files. The five rewritten files have 0 errors, as before the rewrite. The rest of the app has the same 43 errors with or without K3, from CodeImage workspace packages that are older than `origin/main`. It also has 6 `StyleRule` errors in `.css.ts` files that only appear because the mapped kit resolves a second copy of `@vanilla-extract/css`.

The gate holds. No dialog or popover part is missing for these five callers.

## What the rewrite shows

- **Parts always carry the kit style.** `Dialog.Content` adds the kit panel class and `Popover.Content` the kit content class under the caller's class. `Sheet`, the What's new coachmark, the shortcut panel and the export confirmation style their own surface completely. They now also receive the kit background, radius, padding, shadow and entry animation, and which one wins depends on stylesheet order. C1 must screenshot-diff these four surfaces. If the kit style leaks, the parts need an unstyled mode. That decision is open.
- **The ready `Dialog` does not forward attributes to its panel.** `ShortcutHelp` marks the panel with `data-shortcut-overlay`, so its modal variant uses the parts and not the ready `Dialog`.
- **Caller-specific focus targets stay.** `ShortcutHelp` sends focus to its button or to the settings trigger, and `NewDot` to the next tabbable element. Both keep their own `onCloseAutoFocus`. The kit's default focus return replaces only the plain "back to the opener" case.
- **Escape handling in `Sheet` stays** until K4 lands the segmented-control Escape fix.
- **Nine more files** import Kobalte dialog or popover (`PhoneSteps`, `Showcase`, `CommandMenu`, `ControlOverlay`, `ExportControl`, `export-styles/panel`, `sheet`, `video`, `dock/index`). The design maps each to the ready component or the same parts used here. They were not rewritten in this pilot.
