## Usage

```tsx
import { createSignal } from 'solid-js';
import { Pagination } from '@codeui/kit';

export function SnippetPages() {
  const [page, setPage] = createSignal(1);
  return <Pagination pages={12} page={page()} onChange={setPage} />;
}
```

## API

`Pagination` renders a `nav` with one `IconButton` per page. The current page uses the primary theme.
It is built on `createPagination` from `@solid-primitives/pagination`, not on Kobalte, so its options pass through.
