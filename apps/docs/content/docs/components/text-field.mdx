## Usage

```tsx
import { createSignal } from 'solid-js';
import { TextField } from '@codeui/kit';

export function SnippetSettings() {
  const [name, setName] = createSignal('untitled');
  return (
    <>
      <TextField
        label="Snippet name"
        placeholder="my-snippet"
        description="Used as the file name of the export."
        value={name()}
        onChange={setName}
      />
      <TextField
        label="Share link"
        value="codeimage"
        validationState="invalid"
        errorMessage="Enter a full URL."
      />
    </>
  );
}
```

## API

`TextField` wraps Kobalte's `TextField` root and renders its label, input, description, and error message.
Kobalte's root props such as `name`, `disabled`, `readOnly`, and `required` pass through.
Native input attributes such as `type`, `autocomplete`, and the `aria-*` set go to the `input` element.
