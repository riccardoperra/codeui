## Usage

```tsx
import { createSignal } from 'solid-js';
import { Button, Dialog, DialogPanelContent, DialogPanelFooter } from '@codeui/kit';

export function DeleteSnippet() {
  const [open, setOpen] = createSignal(false);
  return (
    <>
      <Button theme="primary" onClick={() => setOpen(true)}>
        Open dialog
      </Button>
      <Dialog open={open()} onOpenChange={setOpen} title="Delete snippet" size="sm">
        <DialogPanelContent>
          The snippet and its export history are removed. This cannot be undone.
        </DialogPanelContent>
        <DialogPanelFooter>
          <Button theme="secondary" onClick={() => setOpen(false)}>
            Cancel
          </Button>
          <Button theme="negative" onClick={() => setOpen(false)}>
            Delete
          </Button>
        </DialogPanelFooter>
      </Dialog>
    </>
  );
}
```

## API

`Dialog` renders the overlay, the panel, and a header with the title and a close button. Put the body in `DialogPanelContent` and the actions in `DialogPanelFooter`.
It also accepts Kobalte's dialog root options, such as `modal` and `preventScroll`.

## Styled parts

When the ready component does not fit the layout, compose the styled parts from `@codeui/kit/dialog`.
Each part carries the kit styles and a `data-cui` attribute, and wraps the matching Kobalte primitive.

<SolidDemo name="dialog-parts" />

```tsx
import { createSignal } from 'solid-js';
import { Button } from '@codeui/kit';
import * as D from '@codeui/kit/dialog';

export function ExportDialog() {
  const [open, setOpen] = createSignal(false);
  return (
    <D.Root open={open()} onOpenChange={setOpen}>
      <D.Trigger as={Button} theme="secondary">
        Export as video
      </D.Trigger>
      <D.Portal>
        <D.Overlay />
        <D.Positioner size="sm">
          <D.Content size="sm">
            <D.Header>
              <D.Title>Export as video</D.Title>
              <D.CloseButton />
            </D.Header>
            <D.Description>Pick a format and a frame rate.</D.Description>
            <D.Body>The export runs in the background. You can keep editing.</D.Body>
            <D.Footer>
              <Button theme="primary" onClick={() => setOpen(false)}>
                Start export
              </Button>
            </D.Footer>
          </D.Content>
        </D.Positioner>
      </D.Portal>
    </D.Root>
  );
}
```

| Part | Renders | `data-cui` |
| --- | --- | --- |
| `Root` | Kobalte dialog root, holds the open state | none |
| `Trigger` | Button that opens the dialog | `dialog-trigger` |
| `Portal` | Portal to `document.body` or `mount` | none |
| `Overlay` | Scrim behind the panel | `dialog-overlay` |
| `Positioner` | Centers the panel, takes `size` | `dialog-positioner` |
| `Content` | The panel, takes `size` | `dialog-panel` |
| `Header` | Row with the title and the close button | `dialog-panel-title` |
| `Title` | Accessible heading | `dialog-title` |
| `Description` | Accessible description | `dialog-description` |
| `CloseButton` | Icon button that closes the dialog | `dialog-close-button` |
| `Body` | Scrolling content area | `dialog-panel-content` |
| `Footer` | Row of actions | `dialog-panel-footer` |
