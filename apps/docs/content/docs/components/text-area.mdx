## Usage

```tsx
import { createSignal } from 'solid-js';
import { TextArea } from '@codeui/kit';

export function SnippetEditor() {
  const [code, setCode] = createSignal("const greeting = 'Hello CodeImage';");
  return (
    <TextArea
      label="Snippet"
      description="Paste the code to render."
      placeholder="Paste your code"
      value={code()}
      onChange={setCode}
    />
  );
}
```

## API

`TextArea` wraps Kobalte's `TextField` root with a `TextField.TextArea` control.
Kobalte's root props such as `name`, `disabled`, `readOnly`, and `required` pass through.
It takes the same field props as [TextField](/docs/components/text-field).
