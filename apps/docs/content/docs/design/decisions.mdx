## How a rule changes

Every rule in Inkstone was decided by reviewing a working build. None comes from a mockup. A rule changes the same way:

1. Build the alternative next to the current one: an Experiment in the app, or a story in the kit.
2. Check it in dark and light at 1440×900, 1024×768 and 390×844.
3. If the maintainer picks it, make it the default, delete the version that lost, and update `DESIGN.md` and this site in the same pull request.

## Tried and rejected

| Tried | Why it was rejected | Instead |
| --- | --- | --- |
| Compact bordered panels, 28px rows, a 300px panel | "troppo compatto e con bordi" | Islands, 36px rows, 360px |
| Several accordion sections open | The panel scrolled further with each click | One open section |
| "More / Less" inside a section | It hid options without making the panel clearer | Everything visible |
| Each section restyled as its own island | It lost the accordion's continuity | The accordion header with an icon |
| A hybrid of rail and accordion | "poco sensato" | One navigation, chosen in Settings |
| Inline dropdowns | "devi scrollare" | Overlays anchored to the row |
| A dock with its own row | The canvas shrank when a menu opened | A floating bar |
| A dimmed modal for pickers | It hid the content being changed | No backdrop |
| Code miniatures as theme thumbnails | All themes looked alike at card size | A window schematic in the theme's colours |
| A palette strip per theme | It showed colours, not the look | The same schematic |
| Full-width buttons in toasts and dialogs | "orrendi" | Inline action; ghost tertiary on the left |
| A floating chip with × over the code | "arraffazzonato" | A marker in the gutter |
| Dropdowns to manage animation steps | Indirect and slow | Inline cards and direct manipulation |
| Draggable bezier handles | Too fiddly for the value they add | Read-only curve and a typed value |
| A blocking "What's new" dialog | It interrupted work | Corner card, dots, archive |
| A toast pointing to "7 new things" in Settings | It sent the user away from their work | Dots on the controls themselves |
| A 9.5px timeline label | Unreadable | 11px minimum |
| Glass window style, dot grid backgrounds | Glossy and busy | Hairline, flat or accent wash |
| `title` attributes for descriptions | Slow, unstyled, unreachable by touch | A hover card |
| A status footer for ambient state | "un po fuorviante" | A header control shown only when it needs action |
| A full screen with "Back to …" | It hid the work | A tab in an island |
| A formatting toolbar under a text input | "non servono a niente" | Shortcuts that render as you type |
| A generic icon and the same label on every row | Every row looked the same | The item's own mark in the leading slot |

## Where the kit disagrees with Inkstone

The kit's tokens were measured from CodeImage, so they carry CodeImage's drift along with its decisions. These are the known gaps, each one waiting for a decision.

| Area | Today | Proposal |
| --- | --- | --- |
| Surface names | `surface-canvas` is the island, `surface-panel` is the page | Name by role: page, island, field, floating |
| Floating fill | Kit menu `#282828`; dialog and command menu `#1d1d1d` | One floating fill |
| Light ramp | Island and field almost identical; CodeImage patches it in seven places | A light ramp with a visible field step |
| Text greys | Eight tokens and five greys in dark mode; light default and muted identical; inverted hierarchy in CodeImage light | Primary, secondary and disabled |
| Selection | Kit listbox fills the selected row with blue | Neutral fill |
| Radius | Eleven tokens; buttons at 9px, dialogs at 14px, the toolbar at 18px | The nesting table |
| Selection ring | Drawn with inset shadow, outline or border in different places | `outline` with a negative offset |
| Focus | Mostly 2px offset, 3px in the accordion | 2px offset, inside the row in packed lists and toolbars |
| Motion | Button press 200ms `ease`; focus `ease-in`; dialog `ease-in-out` keyframes | The movements on the Motion page |
| Island gap | CodeImage sits 8px from the edge and between islands | 6px (`--cui-space-1-5`) |
| Breakpoints | 767, 768 and 769px | 768 / 769 only |
| Export colour | CodeImage's Export still uses the old kit blue `#0072f5` | `--cui-action-brand-base` |
| Tags, keycaps, grips | Three tag styles, three keycap styles, two grips | One each |

## Open questions

- **Modes that take space.** CodeImage's Animate timeline moves the frame when it opens. Should a mode float like every other panel, or is it allowed to take space? See [Layout](/docs/design/layout).
- **Light mode.** Light mode is a supported theme, but it has received less review than dark mode. It needs its own pass through every rule on these pages.
