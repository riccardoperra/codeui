## Usage

Pass the total page count in `pages`. Page numbers start at 1. Use `defaultPage` for local state or set `page` and handle `onChange`. `maxPages` limits the number of visible page buttons. Set `showFirst` or `showLast` to add controls for the ends of the range. Set `showPrev` or `showNext` to `false` to hide a step control.
