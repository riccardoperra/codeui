## Usage

Use `minValue`, `maxValue`, and `step` to express the valid range. Pass `formatOptions` when the value needs a locale-aware format.

See the [React Aria NumberField API](https://react-spectrum.adobe.com/react-aria/NumberField.html) for the underlying behavior.
