## Usage

Label the slider. Use `minValue`, `maxValue`, and `step` to express the range. Pair it with a number field when exact entry helps.

See the [React Aria Slider API](https://react-spectrum.adobe.com/react-aria/Slider.html) for the underlying behavior.
