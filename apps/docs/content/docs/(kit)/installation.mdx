## Requirements

The component package supports Solid `^1.9.8`. Its styles are compiled with vanilla-extract when the library is built. Your app loads ordinary CSS and does not need a vanilla-extract plugin.

## Install

```sh
pnpm add @codeui/kit @codeui/styles solid-js@^1.9.8
pnpm add -D vite vite-plugin-solid
```

## Configure Vite

```ts title="vite.config.ts"
import { defineConfig } from "vite";
import solid from "vite-plugin-solid";

export default defineConfig({
	plugins: [solid()],
});
```

## Load the styles

Import the theme once in your app entry, followed by the components you use.

```ts title="entry.tsx"
import "@codeui/styles/theme.css";
import "@codeui/styles/button.css";
import "@codeui/styles/text-field.css";
```

Each component stylesheet includes the shared styles it needs. JavaScript component imports do not load CSS automatically. A component whose stylesheet is missing remains unstyled.

To load the theme and every component with one import, use `@codeui/styles/all.css` instead. Selective files preserve all variants and runtime states of that component. They do not remove unused selectors within a file.

## Pick a theme

Set `data-cui-theme="dark"` or `data-cui-theme="light"` on the document's `html` element. Portalled content then inherits the page theme too. Without an explicit attribute, the theme follows the system color scheme.

See [Theming](/docs/foundations/theming) for plain CSS overrides. Applications that author their own vanilla-extract styles still configure their own plugin for those files. The kit does not require it.

## CSS without Solid

Install only `@codeui/styles` to use the compiled CSS in HTML or another rendering system. It does not require a framework runtime. Load `theme.css` and the component files through your bundler or ordinary stylesheet links.

The CSS provides appearance and state styling. The caller supplies markup, accessible names and behavior. Focus management, positioning, keyboard navigation, gestures and virtualized lists belong to the Solid components.

## Server rendering

The Solid fixture selects the package's `solid` condition and uses `solid({ ssr: true })`. It does not run vanilla-extract. The current portal behavior omits Dialog and Popover bodies from the server HTML. CSS extraction does not change that behavior. Keep server content outside those portals when it must appear before hydration.

The packed-consumer check and its remaining portal assertion are documented in `docs/kit-2026/consumer.md` and `examples/` in the repository.
