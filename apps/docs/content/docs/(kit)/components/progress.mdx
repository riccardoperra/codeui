## When to use

Use Progress for exports with a known frame count or another task whose completion you can measure.

## When to choose another component

Use [Spinner](/docs/components/spinner) for compact activity with no known total. Use [Skeleton](/docs/components/skeleton) for the shape of content that has not loaded.

## Variants

### Sizes

<SolidDemo name="progress/sizes" />

`sm` is the default track height. `md` makes the track taller. Progress has no tone or appearance variants.

## States

<SolidDemo name="progress/states" />

`value` defaults to 0 in the range 0 to 100. `minValue` and `maxValue` define another range. `indeterminate` shows unknown completion. `getValueLabel` formats the value text. Kobalte leaves ValueLabel empty while indeterminate and does not call `getValueLabel`. The parts example renders a separate styled value label with “Preparing…” instead of a percentage.

Progress renders an optional Label, an optional ValueLabel, and Track with Fill. `showValue` defaults to false. Name the progressbar with `label`, `aria-label`, or `aria-labelledby`.

## Styles export

### `progressStyles`

`progressStyles` is typed as `ProgressStyles`. Each part function returns a class string. Use it when you own the markup and semantics. `root()`, `label()`, `track()`, `fill()`, and `valueLabel()` return fixed classes. The functions accept `ProgressVariants`, but size is selected by `data-size="md"` on the root ancestor, not by the argument. The export is available from both `@codeui/kit` and `@codeui/kit/progress`.

## Accessibility

### Keyboard

Progress is non-interactive and has no keyboard commands. It does not add a tab stop.

### ARIA

Root renders `role="progressbar"` with `aria-valuemin` and `aria-valuemax`. Determinate progress includes `aria-valuenow` and formatted `aria-valuetext`. Indeterminate progress omits both value attributes. Label connects through `aria-labelledby`. ValueLabel is visual output, not a live announcement of each update.

### Focus

Mounting or removing the component does not move focus. There is no open or close focus cycle. The containing control or application owns focus.

### Reduced motion

Determinate Fill follows the value without a transition. Indeterminate Fill spans the track and pulses its opacity. Under `prefers-reduced-motion: reduce`, the pulse stops and the full-width fill stays visible. The bar remains indeterminate.

## SSR notes

The component renders inline on the server. It has no portal or client-only effect. Use the same initial props on the server and client. Kobalte generates IDs for the label relationship. Keep the component tree stable through hydration.

## Theming hooks

The component reads these theme variables.

- `--cui-action-brand-base`
- `--cui-font-size-caption`
- `--cui-motion-duration-slow`
- `--cui-motion-ease-out`
- `--cui-radius-full`
- `--cui-space-1`
- `--cui-space-2`
- `--cui-surface-input-accent`
- `--cui-text-default`
- `--cui-text-hint`
- `--cui-text-label`

Kobalte also provides `--kb-progress-fill-width` for determinate width.

Defaults come from the kit theme. See [Color](/docs/design/color), [Typography](/docs/design/typography), [Space and shape](/docs/design/space-and-shape), and [Motion](/docs/design/motion).
