## When to use

Use Tabs to switch between related panels, such as a snippet's code and settings.

## When to choose another component

Use [SegmentedControl](/docs/components/segmented-control) to choose a compact setting such as an export format or preview mode.
Tabs associates each trigger with a content panel. SegmentedControl represents a setting value and does not require a panel for each choice.

## Anatomy

| Export | Renders | `classes` key | `data-cui` | Role |
| --- | --- | --- | --- | --- |
| `Tabs` | `div` | none | `tabs` | Root container |
| `TabsList` | `div` | none | none | tablist |
| `TabsHeader` | `button` | none | none | tab |
| `TabsContent` | `div` | none | none | tabpanel |
| Internal indicator | `div` | none | none | Visual indicator |

Each public part merges its `class` with kit styles. Tabs has no `classes` map.
Only the root has a kit `data-cui` attribute. Kobalte supplies state and orientation attributes on its parts.

## Variants

### Inline indicator

<SolidDemo name="tabs/inline" />

`theme="inline"` makes TabsList insert an indicator aligned with the selected header.
The default theme has no indicator. The theme does not change panel behavior.
`TabsIndicator` exists in the implementation but is not exported from the package root.

### Vertical orientation

<SolidDemo name="tabs/vertical" />

`orientation="vertical"` puts headers in a column and panels beside them. It also changes the navigation keys to Up Arrow and Down Arrow.

## States

### Disabled and manual activation

<SolidDemo name="tabs/manual" />

A disabled header cannot receive keyboard focus or activate its panel.
The default activation mode selects a tab when it receives focus. `activationMode="manual"` keeps selection unchanged until Enter or Space.
Use manual activation when selecting a panel starts expensive work.

## Accessibility

### Keyboard

| Key | Action |
| --- | --- |
| Tab | Enters the selected tab, then moves into the panel or next focusable element. |
| Left Arrow, Right Arrow | Moves between enabled horizontal tabs. |
| Up Arrow, Down Arrow | Moves between enabled vertical tabs. |
| Home, End | Moves to the first or last enabled tab. |
| Enter, Space | Activates a focused tab in manual mode. |

### ARIA

TabsList has `role="tablist"` and `aria-orientation`. Headers have `role="tab"`, `aria-selected`, and `aria-controls`.
Panels have `role="tabpanel"` and `aria-labelledby` linked to their header. Disabled headers expose `aria-disabled`.

### Focus

Arrow navigation keeps focus on the headers. Activating a tab does not move focus into its panel.
There is no open or close cycle. When removing a selected dynamic tab, choose a remaining value before removing its header.

## SSR notes

The root, list, headers, and initially selected panel render on the server. Inactive panels mount when selected unless `forceMount` is set.
Indicator geometry is measured on the client. Keep initial values and tab IDs stable for hydration. There is no portal.

## Theming hooks

Tabs reads `--cui-border-divider`, `--cui-border-width`, `--cui-action-neutral-hover`, `--cui-text-muted`, `--cui-text-default`, and `--cui-accent-selection`.
Text and spacing use `--cui-font-size-sm`, `--cui-font-weight-semibold`, `--cui-space-2`, and `--cui-space-4`.
Transitions use `--cui-motion-duration-normal` and `--cui-motion-duration-fast` with `--cui-motion-ease-out`.
The current kit draws a line below or beside the tablist, which predates Inkstone's line rule. The inline indicator slides in 160ms when you click a tab; arrow keys move it instantly (Inkstone §7.1), and reduced motion never slides it. A focused header shows the 2px `--cui-focus-color` ring on `:focus-visible`. Header text sets `--cui-font-line-height-sm`.
