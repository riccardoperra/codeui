## When to use

Use Badge for a snippet state, export format, or short count beside content.

## When to choose another component

Use [Button](/docs/components/button) for an action. Use [Alert](/docs/components/alert) for a message with an explanation or recovery action.

### Tones

## Styles export

### `badgeStyles`

Call `badgeStyles.root()`, `icon()`, and `label()` for the part classes. `BadgeStyles` types these helpers.

In CSS-only markup, use `cui-badge` with `data-size`, `data-tone`, and `data-variant`. For example, `data-size="sm" data-tone="info" data-variant="outline"` selects the small info badge with an outline.

## Accessibility

### Keyboard

Badge is non-interactive and has no keyboard commands. It does not add a tab stop.

### ARIA

Kobalte renders a non-interactive `span` with `role="status"`, which has implicit polite live-region semantics. Changes can be announced. Icon is hidden from assistive technology. `textValue` supplies a plain text alternative when the label contains rich content.

### Focus

Mounting or removing the component does not move focus. There is no open or close focus cycle. The containing control or application owns focus.

## SSR notes

The component renders inline on the server. It has no portal or client-only effect. Use the same initial props on the server and client. No request-shared state is created by the kit wrapper.
