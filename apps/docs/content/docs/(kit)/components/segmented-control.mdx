## When to use

Choose between two to four short options while you work, such as editor themes.

## When to choose another component

Use [RadioList](/docs/components/radio-list) for form choices with native radio inputs. Use [OptionCard](/docs/components/option-card) when a visual preview helps you choose.

`xs`, `sm`, `md`, and `lg` are 28px, 36px, 44px, and 52px at comfortable density. The default is `sm`. Density adjusts the height without changing the font size. Each segment fills the track height inside its padding. The indicator slides between segments in 160ms when you click; arrow keys and Enter move it instantly, and reduced motion never slides it. `pill` combines with either variant. `accent` fills the indicator with the brand color. `fluid` fills width only. The control keeps its size height even inside the taller demo container. `autoWidth` sets each segment to a 1px base width with equal flex growth and removes horizontal padding. It does not measure text widths.

## Styled parts API

Use `@codeui/kit/segmented-control/parts` to place the segmented control's list and indicator yourself. Keep `List` within `Root`. Put each `Item` and the shared `Indicator` in the list so alignment and keyboard selection follow the same group.

## Accessibility

### Keyboard

| Key                     | Action                                                  |
| ----------------------- | ------------------------------------------------------- |
| Tab                     | Enter or leave the tab list.                            |
| Left Arrow, Right Arrow | Focus the previous or next enabled segment.             |
| Home, End               | Focus the first or last enabled segment.                |
| Enter, Space            | Select the focused segment in manual activation mode.   |
| Escape                  | Call the handler, then forward Escape unless prevented. |

### ARIA

The list has `role="tablist"`. Buttons have `role="tab"` and `aria-selected`. The default activation mode is manual. Arrow keys move focus without selecting. The wrapper renders no tab panels. Supply an accessible name for the group.

### Focus

These controls do not open an overlay or move focus on mount. Disabled controls cannot receive keyboard focus. The enclosing overlay owns focus restoration on close.

## SSR notes

The root, labels, controls, and form inputs render on the server. No part uses a portal. Keep initial values and component order stable between server and client so generated IDs hydrate consistently. Create signals per component instance. Indicator measurement, ResizeObserver, and Escape forwarding start after mount.

SegmentedControl renders tabs and has no native form input. Mirror the controlled selection in a named hidden input. It has no built-in description, required, readOnly, or invalid field API. Associate external hint text with `aria-describedby` when needed.

Escape calls `onEscapeKeyDown`. Unless you call `event.preventDefault()`, the helper forwards a bubbling Escape from the parent so an enclosing Dialog can close. The Dialog example leaves Escape uncancelled. The example restores focus to its opening button in `onCloseAutoFocus`. The second example cancels Escape with `preventDefault()`.
