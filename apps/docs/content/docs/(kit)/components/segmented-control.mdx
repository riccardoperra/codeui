## Usage

```tsx
import { createSignal } from 'solid-js';
import { SegmentedControl, SegmentedControlItem } from '@codeui/kit';

export function ThemeMode() {
  const [theme, setTheme] = createSignal('dark');
  return (
    <SegmentedControl value={theme()} onChange={setTheme}>
      <SegmentedControlItem value="light">Light</SegmentedControlItem>
      <SegmentedControlItem value="dark">Dark</SegmentedControlItem>
      <SegmentedControlItem value="system">System</SegmentedControlItem>
    </SegmentedControl>
  );
}
```

## API

`SegmentedControl` renders the list and a sliding indicator under the selected item. Each option is a `SegmentedControlItem`.
It wraps Kobalte's `Tabs` with manual activation and a fixed horizontal orientation, so Kobalte's root props such as `disabled` pass through.
`SegmentedControlItem` wraps `Tabs.Trigger` and takes its props, such as `value` and `disabled`.
