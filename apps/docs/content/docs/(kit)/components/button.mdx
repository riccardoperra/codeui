## Usage

```tsx
import { Button } from '@codeui/kit';

export function ExportActions() {
  return (
    <>
      <Button theme="primary">Export</Button>
      <Button theme="secondary">Copy link</Button>
      <Button theme="secondary" variant="ghost">
        Reset theme
      </Button>
      <Button theme="primary" loading>
        Exporting
      </Button>
    </>
  );
}
```

## API

`Button` wraps Kobalte's `Button` root, so Kobalte's props such as `disabled` and `as` pass through.
It renders a native `button` by default and sets `data-cui="button"`, `data-theme`, and `data-size` on it.
