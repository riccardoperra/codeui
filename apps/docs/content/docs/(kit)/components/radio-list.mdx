## When to use

Choose one named value from a visible list of export options.

## When to choose another component

Use [SegmentedControl](/docs/components/segmented-control) for a compact row of short choices. Use [OptionCard](/docs/components/option-card) when previews or descriptions help compare options. RadioList retains native form radio semantics.

## Accessibility

### Keyboard

| Key        | Action                               |
| ---------- | ------------------------------------ |
| Tab        | Enter or leave the group.            |
| Arrow keys | Move to and select an enabled radio. |
| Space      | Select the focused radio.            |

### ARIA

The root has `role="radiogroup"`. Item inputs are native radios with checked state. Labels name each item. Description and error components associate hint text with the field. `validationState="invalid"` exposes invalid state. Supply a visible label or an accessible name.

### Focus

These controls do not open an overlay or move focus on mount. Disabled controls cannot receive keyboard focus. Read-only controls remain focusable and do not change value.

## SSR notes

The root, labels, controls, and form inputs render on the server. No part uses a portal. Keep initial values and component order stable between server and client so generated IDs hydrate consistently. Create signals per component instance.
