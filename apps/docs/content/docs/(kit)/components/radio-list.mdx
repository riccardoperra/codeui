## Usage

```tsx
import { createSignal } from 'solid-js';
import { RadioList, RadioListItem } from '@codeui/kit';

export function ExportFormat() {
  const [format, setFormat] = createSignal('png');
  return (
    <RadioList
      label="Export format"
      description="SVG keeps the text selectable."
      value={format()}
      onChange={setFormat}
    >
      <RadioListItem value="png" label="PNG" />
      <RadioListItem value="svg" label="SVG" />
      <RadioListItem value="jpeg" label="JPEG" />
    </RadioList>
  );
}
```

## API

`RadioList` renders the label, the items, the description, and the error message. Each option is a `RadioListItem`.
It wraps Kobalte's `RadioGroup`, so Kobalte's root props such as `name`, `disabled`, `required`, and `validationState` pass through.

`RadioListItem` wraps Kobalte's `RadioGroup.Item`. Its `classes` apply to that item only and merge with the list's `classes`.
