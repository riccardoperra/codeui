The kit has 36 components, grouped by purpose. Each link includes live examples and the public API.

## Actions

- [Button](/docs/components/button): A clickable action, styled by theme, size, and variant.
- [IconButton](/docs/components/icon-button): A button that shows only an icon and carries an accessible name.
- [Link](/docs/components/link): A styled anchor for navigation inside text or toolbars.

## Layout and text

- [Kbd](/docs/components/kbd): A keycap that shows a key or a keyboard shortcut.
- [Stack](/docs/components/stack): A flex container that spaces its children with token gaps.
- [Table](/docs/components/table): A native table with Inkstone styles.
- [Text](/docs/components/text): Text set in the kit type scale, with tones and polymorphic headings.

## Fields and selection

- [Checkbox](/docs/components/checkbox): A box that toggles one option on or off.
- [Combobox](/docs/components/combobox): A text input that filters a list of options as the user types.
- [NumberField](/docs/components/number-field): A text field for numbers, with steppers, limits, and formatting.
- [OptionCard](/docs/components/option-card): A group of large selectable cards, each with a label, a description, and an optional preview.
- [RadioList](/docs/components/radio-list): A list of radio buttons for choosing one option.
- [SegmentedControl](/docs/components/segmented-control): A row of mutually exclusive segments for switching between a few options.
- [Select](/docs/components/select): A button that opens a list of options and shows the chosen one.
- [Slider](/docs/components/slider): A thumb on a track for choosing a number in a range.
- [Switch](/docs/components/switch): A toggle that turns a setting on or off immediately.
- [TextArea](/docs/components/text-area): A multi-line text field.
- [TextField](/docs/components/text-field): A single-line text input with a label, a description, and an error message.

## Navigation and collections

- [Accordion](/docs/components/accordion): Stacked sections that expand to show their content.
- [Listbox](/docs/components/listbox): A list of selectable options that stays visible on the page.
- [Pagination](/docs/components/pagination): Buttons for moving between pages of a long result set.
- [Tabs](/docs/components/tabs): A row of tabs that switches between panels of content.
- [VirtualizedListbox](/docs/components/virtualized-listbox): A Listbox that renders only the visible rows of a long collection.

## Feedback

- [Alert](/docs/components/alert): A message inside the page that reports a status.
- [Badge](/docs/components/badge): A short, non-interactive status label.
- [Progress](/docs/components/progress): A bar that shows how much of a task is done.
- [Skeleton](/docs/components/skeleton): A placeholder shape shown while content loads.
- [Spinner](/docs/components/spinner): An animated indicator for work of unknown length.
- [Toast](/docs/components/toast): Short notifications that appear over the page and dismiss themselves.

## Overlays

- [CommandMenu](/docs/components/command-menu): A searchable palette of commands opened from the keyboard.
- [Dialog](/docs/components/dialog): A modal window over the page, for a decision that blocks the user.
- [DropdownMenu](/docs/components/dropdown-menu): A menu of actions opened from a trigger.
- [Popover](/docs/components/popover): A floating panel anchored to a trigger, for content the user opens on demand.
- [Sheet](/docs/components/sheet): A panel that slides in from an edge of the screen.
- [Tooltip](/docs/components/tooltip): A short label that appears on hover or focus.
