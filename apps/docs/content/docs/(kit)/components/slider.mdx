## When to use

Choose a numeric value in a useful range, such as background opacity.

## When to choose another component

Use NumberField when you need an exact typed value. Pair a slider with a number field when both input methods are useful.

## Styles export

### `sliderStyles`

`sliderStyles` maps each part name to a function that returns its class. Set `data-orientation="vertical"` on custom track and fill elements for a vertical slider. `SliderStyles` types the map and `SliderParts` exposes the Solid components.

## Accessibility

### Keyboard

| Key                    | Action                                                                                 |
| ---------------------- | -------------------------------------------------------------------------------------- |
| Tab                    | Focus the thumb.                                                                       |
| Right Arrow, Up Arrow  | Increase by one step in the default direction.                                         |
| Left Arrow, Down Arrow | Decrease by one step in the default direction.                                         |
| Page Up, Page Down     | Increase or decrease by one tenth of the range, snapped to step and at least one step. |
| Shift + Arrow key      | Change by the page step.                                                               |
| Home, End              | Set the minimum or maximum value.                                                      |

### ARIA

The thumb has `role="slider"`, `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, and `aria-valuetext`. `getValueLabel` formats both the visible value and the spoken value. Orientation and direction affect arrow behavior. The ready API takes scalar numbers. Styled Root takes arrays for multiple thumbs. Description and error components associate hint text with the field. `validationState="invalid"` exposes invalid state. Supply a visible label or an accessible name.

### Focus

These controls do not open an overlay or move focus on mount. Disabled controls cannot receive keyboard focus. Read-only controls remain focusable and do not change value.

## SSR notes

The root, labels, controls, and form inputs render on the server. No part uses a portal. Keep initial values and component order stable between server and client so generated IDs hydrate consistently. Create signals per component instance.
