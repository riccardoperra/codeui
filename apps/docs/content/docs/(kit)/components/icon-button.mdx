## Usage

```tsx
import { IconButton, icons } from '@codeui/kit';

export function SnippetNavigation() {
  return (
    <>
      <IconButton theme="secondary" aria-label="Previous snippet">
        <icons.PreviousIcon />
      </IconButton>
      <IconButton theme="secondary" aria-label="Next snippet">
        <icons.NextIcon />
      </IconButton>
      <IconButton theme="tertiary" size="sm" aria-label="Close panel">
        <icons.CloseIcon />
      </IconButton>
    </>
  );
}
```

## API

`IconButton` is a `Button` with equal width and height and no padding.
It wraps Kobalte's `Button` root, so Kobalte's props such as `disabled` and `as` pass through.
The icon has no visible text, so `aria-label` is required.
