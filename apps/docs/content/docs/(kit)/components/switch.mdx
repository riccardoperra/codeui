## When to use

Turn a setting on or off immediately, such as line numbers in the editor preview.

## When to choose another component

Use [Checkbox](/docs/components/checkbox) for agreement or independent options submitted together. Switch has no indeterminate state.

## Variants

<SolidDemo name="switch/sizes" />

`md` is a 36×22 track with a 16px thumb, as in CodeImage. `sm` is a 28×16 track with a 12px thumb. On a touch screen both grow to 44×26 with a 20px thumb, so the target is at least 40px. The thumb carries `--cui-shadow-thumb`, so it stays visible on a light track.

## Motion

A pointer toggle slides the thumb in 120ms with the ease-out curve and fades the track colour in 120ms. A toggle from the keyboard is instant, and the 2px focus ring shows only after keyboard input: Kobalte focuses the input from script after a click, which the browser marks `:focus-visible`, so the kit reads the last input from `<html data-cui-input>` instead. Reduced motion keeps the colour fade and drops the slide.

## Styles export

### `switchStyles`

`switchStyles` maps each part name to a function that returns its class. Set `data-size="sm"` on a custom control to select the compact track. `SwitchStyles` types the map and `SwitchParts` exposes the Solid components.

Import `switchStyleProps` from `@codeui/styles/switch` to bind the base class and attributes in one step. For example, spread `switchStyleProps.control({ size: "sm", class: "preview-track" })` on a custom control. A standalone part leaves `data-size` absent when the caller leaves size unspecified. The behavior adapter supplies checked and disabled states.

## Accessibility

### Keyboard

| Key   | Action                    |
| ----- | ------------------------- |
| Tab   | Focus the control.        |
| Space | Toggle the checked state. |

### ARIA

The input exposes `role="switch"` and `aria-checked`. Description and error components associate hint text with the field. `validationState="invalid"` exposes invalid state. Supply a visible label or an accessible name.

### Focus

These controls do not open an overlay or move focus on mount. Disabled controls cannot receive keyboard focus. Read-only controls remain focusable and do not change value.

## SSR notes

The root, labels, controls, and form inputs render on the server. No part uses a portal. Keep initial values and component order stable between server and client so generated IDs hydrate consistently. Create signals per component instance.
