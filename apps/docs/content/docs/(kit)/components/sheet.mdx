## When to use

Sheet presents a panel over your content, including a phone panel or export options. Opening a sheet does not reflow the frame.

## When to choose another component

Use [Dialog](/docs/components/dialog) for a blocking decision. Use [Popover](/docs/components/popover) for a picker anchored to a control.

## Variants

<SolidDemo name="sheet/sides" />

`side` accepts `left`, `right`, and `bottom`. Bottom is the default.

<SolidDemo name="sheet/nonmodal" />

Modal sheets render a scrim and trap focus. `modal={false}` removes the scrim and leaves the page interactive.

<SolidDemo name="sheet/draggable" />

`draggable` adds a handle only to a bottom sheet. The placement union rejects draggable left and right sheets.

<SolidDemo name="sheet/motion" />

`motion="auto"` slides on pointer open and close. Keyboard actions do not animate. Reduced motion replaces the slide with a fade. `motion="none"` disables presence animation.

A downward drag tracks the handle 1:1. Dragging above the open position applies rubber band resistance. A downward flick above 0.5 px/ms or a drag beyond 35% of the sheet height dismisses it. Short drags and `pointercancel` settle back open. A new grab can interrupt the settle. Reduced motion skips the settle animation.

Drag events belong to `Handle`, not `Body`. Scrollable body content scrolls without starting a dismiss gesture. The draggable demo includes a scroll region for this distinction.

## States

The live demo controls `open` with `onOpenChange`. Parts also support `defaultOpen` for uncontrolled state. Closed content unmounts after its exit animation unless Kobalte force mounting is enabled.

## Styles export

### `sheetStyles`

`SheetStyles` maps each anatomy part key to a function that returns a class string. Only `content({ side })` uses the optional side variant. `trigger()` returns an empty string. Styles are exported from `@codeui/kit/sheet`. Use these functions with custom markup when you provide the required semantics and behavior. Styles alone do not manage focus or state.

## Accessibility

### Keyboard

| Key | Action |
| --- | --- |
| Enter or Space on trigger | Opens the sheet. |
| Escape | Closes the innermost sheet. |
| Tab or Shift+Tab | Moves through focusable controls. Modal sheets keep focus inside. |
| Enter or Space on handle or close button | Closes the sheet. |

### ARIA

Content has `role="dialog"`, a title link through `aria-labelledby`, and a description link through `aria-describedby`. Modal content has `aria-modal`. Without a visible title, provide `aria-label`. Trigger exposes open state and the controlled content ID.

### Focus

Opening moves focus into the sheet. Modal sheets trap focus. Closing returns focus to Trigger, or to the element focused before opening when no Trigger exists. A nonmodal outside interaction keeps focus on the outside target. `contentProps` can override autofocus through cancellable events.

## SSR notes

Root state can render on the server. Portalled overlay and content render only on the client. Input tracking starts on mount. Supply `mount` only after its element exists in the browser.

## Theming hooks

Sheet reads `--cui-surface-scrim`, `--cui-surface-dialog`, `--cui-text-dialog`, `--cui-text-dialog-title`, `--cui-shadow-dialog`, `--cui-border-width`, `--cui-border-dialog-title`, `--cui-radius-xl`, `--cui-radius-full`, `--cui-action-neutral-active`, and `--cui-text-muted`. Layout uses `--cui-space-1`, `-2`, `-3`, `-4`, `-6`, and `-10`, with the same `--cui-space` prefix.

Typography uses `--cui-font-size-lg`, `--cui-font-size-sm`, `--cui-font-weight-medium`, and `--cui-font-line-height-compact`. Controls use `--cui-control-height-xs`, `--cui-control-height-md`, and `--cui-control-height-xl`. Focus uses `--cui-focus-width`, `--cui-focus-color`, and `--cui-focus-offset`. Motion uses `--cui-motion-duration-panel` and `--cui-motion-ease-out`.

See [Inkstone foundations](/docs/design) for the design rules.
