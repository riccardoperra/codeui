## Usage

```tsx
import {
  Button,
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuPortal,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
  DropdownSubMenu,
  DropdownSubMenuContent,
  DropdownSubMenuTrigger,
} from '@codeui/kit';

export function ExportMenu() {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger as={Button} theme="secondary">
        Export
      </DropdownMenuTrigger>
      <DropdownMenuPortal>
        <DropdownMenuContent>
          <DropdownMenuItem rightSlot="⌘S">Save as PNG</DropdownMenuItem>
          <DropdownMenuItem rightSlot="⇧⌘S">Save as SVG</DropdownMenuItem>
          <DropdownMenuSeparator />
          <DropdownSubMenu>
            <DropdownSubMenuTrigger rightSlot="›">Copy</DropdownSubMenuTrigger>
            <DropdownMenuPortal>
              <DropdownSubMenuContent>
                <DropdownMenuItem>Copy image</DropdownMenuItem>
                <DropdownMenuItem>Copy link</DropdownMenuItem>
                <DropdownMenuItem>Copy embed code</DropdownMenuItem>
              </DropdownSubMenuContent>
            </DropdownMenuPortal>
          </DropdownSubMenu>
          <DropdownMenuSeparator />
          <DropdownMenuItem disabled>Export as video</DropdownMenuItem>
        </DropdownMenuContent>
      </DropdownMenuPortal>
    </DropdownMenu>
  );
}
```

## API

DropdownMenu is a compound component. Each piece wraps the matching Kobalte `DropdownMenu` part and takes its props.
Handle a click with `onSelect` on the item.

| Export | Wraps | Role |
| --- | --- | --- |
| `DropdownMenu` | `DropdownMenu` | Root. Holds the open state. Default `gutter` of 6. |
| `DropdownMenuTrigger` | `DropdownMenu.Trigger` | Opens the menu. Use `as={Button}` for a kit button. |
| `DropdownMenuPortal` | `DropdownMenu.Portal` | Portals the menu or a submenu to `document.body`. |
| `DropdownMenuContent` | `DropdownMenu.Content` | The menu panel. |
| `DropdownMenuItem` | `DropdownMenu.Item` | One action. Takes `rightSlot`. |
| `DropdownMenuSeparator` | `DropdownMenu.Separator` | Line between groups. |
| `DropdownSubMenu` | `DropdownMenu.Sub` | Root of a nested menu. |
| `DropdownSubMenuTrigger` | `DropdownMenu.SubTrigger` | Item that opens the nested menu. Takes `rightSlot`. |
| `DropdownSubMenuContent` | `DropdownMenu.SubContent` | The nested menu panel. |

The root accepts Kobalte's root props such as `open`, `onOpenChange`, `placement`, and `modal`.
