## When to use

Use Listbox when you need visible options that select one or more values, such as export formats or snippet languages.

## When to choose another component

Use [Select](/docs/components/select) for a collapsed picker. Use [Combobox](/docs/components/combobox) when you need a search field.
Use [VirtualizedListbox](/docs/components/virtualized-listbox) for a long collection.

## Variants

### Selection modes

<SolidDemo name="listbox/selection" />

`single` selects one key. `multiple` selects several keys. `none` allows navigation without selection.
The controlled `value` and `onChange` use a `Set<string>`. Set `selectionBehavior="replace"` for desktop range selection behavior.

### Sizes

<SolidDemo name="listbox/sizes" />

Rows use the shared `sm` height (32px compact, 36px comfortable, 40px touch). The `size` prop controls row typography and shape.
Use `sm` for the Inkstone desktop control height.

## Styled parts API

Use `@codeui/kit/listbox/parts` to control option markup. Pass `options` and `renderItem` to `Root`. The callback receives a collection node. Pass it to `Item` to keep selection and keyboard navigation. Use `ItemLabel`, `ItemDescription`, and `ItemIndicator` to compose the row. Use `Section` for grouped options.

## Accessibility

### Keyboard

| Key | Action |
| --- | --- |
| Tab | Enters the list at the selected or first enabled option, then leaves the list. |
| Up Arrow, Down Arrow | Moves focus between enabled options. |
| Home, End | Moves to the first or last enabled option. |
| Enter, Space | Selects the focused option according to the selection mode. |
| Characters | Moves focus to the next matching text value. |
| Shift + Arrow | Extends a multiple selection when the selection behavior supports ranges. |

### ARIA

The root has `role="listbox"`. Items have `role="option"`, `aria-selected`, and `aria-disabled` when applicable.
Multiple selection adds `aria-multiselectable`. Supply `aria-label` or `aria-labelledby` for the list.
`optionTextValue` provides the plain text used for typeahead when labels contain custom markup.

### Focus

Options take DOM focus. Hover focuses options by default. Disabled options are skipped.
The list stays inline, so there is no open or close cycle and no focus restoration target.

## SSR notes

The list and its options render inline on the server. Keep option keys and initial selection stable between server render and hydration.
There is no portal.

## Theming hooks

The list reads `--cui-surface-menu`, `--cui-surface-menu-hover`, `--cui-text-menu`, `--cui-text-selected`, and `--cui-accent-selection`.
Geometry uses `--cui-radius-xs`, `--cui-radius-sm`, `--cui-radius-lg`, `--cui-control-height-md`, and `--cui-space-1`, `--cui-space-2`, `--cui-space-3`.
Text uses `--cui-font-size-sm`, `--cui-font-size-md`, and `--cui-font-weight-normal`.
The legacy bordered mode reads `--cui-border-width`, `--cui-border-divider`, and `--cui-focus-color`.
The theme also references `--cui-shadow-menu` and `--cui-border-menu`.
Keep the neutral theme and borderless default for Inkstone. The primary highlight and bordered mode are legacy styles.
