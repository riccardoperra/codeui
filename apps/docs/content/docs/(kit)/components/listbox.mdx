## Usage

```tsx
import { Listbox } from '@codeui/kit';

const languages = ['TypeScript', 'Rust', 'Python', 'Go'];

export function LanguageList() {
  return (
    <Listbox
      aria-label="Language"
      options={languages}
      defaultValue={['TypeScript']}
      selectionMode="single"
      size="sm"
      bordered
    />
  );
}
```

## API

`Listbox` wraps Kobalte's `Listbox` and renders each option as a `ListboxItem` with a check indicator.
Kobalte's props such as `selectionMode`, `disallowEmptySelection`, `optionValue`, and `optionTextValue` pass through.
Items take focus on hover. For long lists, use `VirtualizedListbox`.
