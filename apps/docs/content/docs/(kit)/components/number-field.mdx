## Usage

```tsx
import { createSignal } from 'solid-js';
import { NumberField } from '@codeui/kit';

export function FontSize() {
  const [fontSize, setFontSize] = createSignal<number | null | undefined>(14);
  return (
    <NumberField
      label="Font size"
      description="Between 8 and 32 pixels."
      min={8}
      max={32}
      value={fontSize()}
      onChange={setFontSize}
    />
  );
}
```

## API

`NumberField` wraps Kobalte's `TextField` root and adds increment and decrement buttons.
Arrow Up and Arrow Down step the value, and the value is clamped to `min` and `max` on blur.
Kobalte's root props such as `name`, `disabled`, and `required` pass through.
The value is a number, or `null` when the input is empty.
