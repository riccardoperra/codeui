## When to use

Use Alert for a message beside the affected snippet or export control. It stays in the page until your application removes it.

## When to choose another component

Use [Toast](/docs/components/toast) for a temporary notification outside the document flow. Use Text for a static hint that does not need an alert announcement.

## Variants

### Tones

The tones are `neutral`, `info`, `success`, `warning`, and `danger`. The default is `neutral`.

### Icons

<SolidDemo name="alert/icons" />

`showIcon` defaults to false. With `showIcon`, a status tone gets its tone icon. Neutral needs a custom `icon`.

### Width

<SolidDemo name="alert/fluid" />

`fluid` defaults to false for inline width. `fluid={true}` fills the available width.

## Ready API

### `Alert`

Alert renders Root, an optional Icon and Title, Description, and an optional Action. `description` takes precedence over `children`. `title`, `description`, and `action` accept JSX.

## Styles export

### `alertStyles`

`alertStyles` is typed as `AlertStyles`. Each part function returns a class string. Use it when you own the markup and semantics. `root({ tone, fluid })` selects the recipe. The other part functions return fixed classes.

## Accessibility

### Keyboard

| Key            | Action                                  |
| -------------- | --------------------------------------- |
| Tab            | Move to a focusable action you provide. |
| Shift+Tab      | Move to the previous focusable control. |
| Enter or Space | Activate a supplied button.             |

The alert itself has no keyboard commands.

### ARIA

Kobalte Root renders `role="alert"`, an assertive live region. The role applies to every tone, including neutral. Color does not change announcement urgency. Icon is decorative. Title and Description are plain wrappers, without automatic heading or ARIA label relationships.

### Focus

Mounting or removing the component does not move focus. There is no open or close focus cycle. If an action removes the alert while focused, your application must move focus to the next useful control.

## SSR notes

The component renders inline on the server. It has no portal or client-only effect. Use the same initial props on the server and client. No request-shared state is created by the kit wrapper.

- `--cui-action-brand-soft-base`
- `--cui-action-brand-soft-text`
- `--cui-action-caution-base`
- `--cui-action-caution-text`

- `--cui-action-danger-text`
