## When to use

Use TextField for one line of free text, such as a snippet name, a share link, or an email address. It renders the label, the input, the hint, and the error message as one field, and links them for assistive technology.

## When to choose another component

- Use [TextArea](/docs/components/text-area) when the value can span several lines, such as a caption or a code snippet.
- Use [NumberField](/docs/components/number-field) for a number. It parses, clamps, and steps the value for you.
- Use [Select](/docs/components/select) when the value comes from a fixed list, and [Combobox](/docs/components/combobox) when the user types to filter a list.

|             | Error `div`, when invalid and `errorMessage` is set | `errorMessage` | `text-field-error-message` | none |

The root, the label, the input, the hint, and the error carry Kobalte's state attributes: `data-invalid`, `data-valid`, `data-required`, `data-disabled`, and `data-readonly`. The root also carries `data-field-size` when you set `size`.

## Variants

### Size

<SolidDemo name="text-field/sizes" />

`size` sets the input height, the corner radius, and the font size of every part.

| `size` | Input height | Input font size |
| ------ | ------------ | --------------- |
| `xs`   | 30px         | 12px            |
| `sm`   | 36px         | 14px            |
| `md`   | 36px (40px on a phone) | 14px (16px on a phone) |
| `lg`   | 48px         | 16px            |
| `xl`   | 56px         | 18px            |

Inkstone sets desktop controls at 36px. The default `md` is 36px with 14px text on desktop and 40px with 16px text at 768px and narrower, so iOS does not zoom into the field. `sm` stays 36px everywhere with a 9px radius, the size CodeImage's sidebar fields use.

### Theme

<SolidDemo name="text-field/themes" />

`filled` draws the field fill with a transparent border. `inline` drops the fill and the radius and keeps a 2px bottom border, for a field that sits inside a row of text. These are the only two themes the source defines.

### Description

<SolidDemo name="text-field/description" />

`label`, `description`, and `errorMessage` accept JSX, so a hint can hold code, a link, or a formatted value.

## States

### Required, read-only, and disabled

<SolidDemo name="text-field/states" />

`required` sets `required` and `aria-required` on the input. The kit adds no asterisk, so say "required" or "optional" in the label or the hint when it matters. `readOnly` keeps the value selectable and focusable and blocks edits. `disabled` removes the input from the tab order and dims it to 40% opacity.

### Invalid

<SolidDemo name="text-field/invalid" />

Set `validationState="invalid"` to show `errorMessage`, color the border and the text with `--cui-text-danger`, and set `aria-invalid` on the input. The error message renders only while the field is invalid. The kit runs no validation of its own. You decide when the field is invalid.

### Controlled

<SolidDemo name="text-field/controlled" />

Pass `value` and `onChange` to own the value. `onChange` receives the string, not the event. Pass `defaultValue` instead to leave the value to the field. A form reset restores `defaultValue`.

## Styled parts API

Use `@codeui/kit/text-field/parts` to place an input inside a custom field layout. Put `Label`, `Input`, `Description`, and `ErrorMessage` under `Root`. Put value, name, and validation state on `Root`. Put native input attributes such as autocomplete and placeholder on `Input`.

```tsx
import * as F from "@codeui/kit/text-field/parts";

<F.Root name="fileName" defaultValue="untitled">
	<F.Label>File name</F.Label>
	<F.Description>Use the name without an extension.</F.Description>
	<F.Input autocomplete="off" />
</F.Root>
```

## Accessibility

### Keyboard

| Key       | Action                                   |
| --------- | ---------------------------------------- |
| Tab       | Move focus to the input.                 |
| Shift+Tab | Move focus to the previous control.      |
| Enter     | Submit the parent form, as a native input does. |

### ARIA

- The root is a `div` with `role="group"`.
- The label is a `label` element whose `for` points at the input `id`.
- The input gets `aria-labelledby` for the label and `aria-describedby` for the hint and, while invalid, the error message.
- The input gets `aria-invalid`, `aria-required`, `aria-disabled`, and `aria-readonly` from the matching props.
- Without a visible label, pass `aria-label` or `aria-labelledby`. They go to the input.

### Focus

TextField moves no focus on its own. On focus, the border takes `--cui-focus-color`, and `:focus-visible` adds the 2px Inkstone ring with a 2px offset, as CodeImage's fields do. Text inputs match `:focus-visible` for mouse focus too, so the ring shows whenever the field takes focus.

## SSR notes

Every part renders on the server, and none uses a portal. TextField sets the input `id` to `${id}-input` and points the label `for` at it during render, so the server HTML already links the label to the input. Without an `id`, the kit generates one with `createUniqueId`, which matches between the server and the client while the component tree is the same. Kobalte adds `aria-labelledby` and `aria-describedby` after hydration.

<SolidDemo name="text-field/ssr-ids" />

Pass `id` when another element or a test needs a fixed input id. Pass `name` for form data. Without it, the input submits under the root id.

## Theming hooks

TextField reads these variables, through the shared field style:

- Fill, text, and border: `--cui-surface-input`, `--cui-text-input`, `--cui-border-input`, `--cui-border-width`, and `--cui-border-width-strong` for `inline`.
- Hint and placeholder: `--cui-text-hint`.
- Label: `--cui-text-label` and `--cui-font-weight-medium`.
- Focus and errors: `--cui-focus-color` and `--cui-text-danger`.
- Size: `--cui-control-height-xs` to `--cui-control-height-xl`, `--cui-font-size-xs` to `--cui-font-size-lg`, and `--cui-radius-xs` to `--cui-radius-xl`.
- Spacing and motion: `--cui-space-3`, `--cui-motion-duration-fast`, and `--cui-motion-ease-out`.

See [Tokens](/docs/foundations/tokens) for the defaults.
