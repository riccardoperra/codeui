## When to use

Select independent export options or collect agreement before form submission.

## When to choose another component

Use [Switch](/docs/components/switch) for a setting that takes effect immediately. Checkbox also supports a mixed selection through `indeterminate`.

## Accessibility

### Keyboard

| Key   | Action                    |
| ----- | ------------------------- |
| Tab   | Focus the control.        |
| Space | Toggle the checked state. |

### ARIA

The input exposes checkbox semantics, including `aria-checked="mixed"` for indeterminate selection. Description and error components associate hint text with the field. `validationState="invalid"` exposes invalid state. Supply a visible label or an accessible name.

### Focus

These controls do not open an overlay or move focus on mount. Disabled controls cannot receive keyboard focus. Read-only controls remain focusable and do not change value.

## SSR notes

The root, labels, controls, and form inputs render on the server. No part uses a portal. Keep initial values and component order stable between server and client so generated IDs hydrate consistently. Create signals per component instance.
