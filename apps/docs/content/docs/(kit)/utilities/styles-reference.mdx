Part style functions return class-name strings, including an empty string for an unstyled part. They do not render elements or attach behavior, ARIA, state, or `data-*` attributes.
The styled parts already apply these functions. Use the functions directly only when you also own the markup and its state attributes.

The reference below follows the exports in `packages/kit/src/index.tsx` and `packages/kit/src/parts/`.

## `buttonStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose vanilla-extract implementation details.

`button(options)` returns recipe classes. Options are `size` (`xs`, `sm`, `md`, `lg`, `xl`), `theme` (`primary`, `secondary`, `tertiary`, `negative`, `caution`), `variant` (`ghost`), and boolean `block`, `pill`, and `loading`. The recipe defaults to size `md`. `buttonIcon`, `buttonText`, and `buttonTheme` are class strings. `buttonVars` is a CSS variable contract. `ButtonVariants` is the recipe variant type.

## `fieldStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose vanilla-extract implementation details.

`baseFieldVariants(options)` returns recipe classes. Options are `size` (`xs`, `sm`, `md`, `lg`, `xl`) and `theme` (`filled`, `inline`), defaulting to `md` and `filled`. `FieldSizes` contains size names. `baseFieldTheme` is a class string. `baseFieldVars` is a variable contract. `inputHeight` and `fontSize` are variable references. `BaseFieldVariants` is the recipe variant type.

## `fieldErrorStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose vanilla-extract implementation details.

`errorMessage` is a class string for a field error. There are no callable recipes or variants.

## `fieldLabelStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose vanilla-extract implementation details.

`label` is a class string for a field label. There are no callable recipes or variants.

## `textFieldStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose vanilla-extract implementation details.

`baseFieldContainer` and `textField` are class strings. There are no callable recipes or variants.

## `dropdownMenuStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose vanilla-extract implementation details.

`content`, `subMenuContent`, `separator`, `item`, `rightSlot`, and `dropdownMenuTheme` are class strings. `dropdownMenuThemeVars` is a variable contract. There are no callable recipes or variants.

## `popoverStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose vanilla-extract implementation details.

The root namespace exports `content(options)`, a recipe returning a class string with optional `variant: "bordered"`. `title`, `description`, and `popoverTheme` are class strings. `popoverThemeVars` is a variable contract. `PopoverVariants` is the recipe variant type. The subpath object below is a different export with the same name.

## `styleFieldMessage`

Advanced helper from `@codeui/kit` for use inside a vanilla-extract style definition.
It accepts a complete map from each size (`xs`, `sm`, `md`, `lg`, `xl`) to a font size with the same choices.
It returns a style object with `selectors`, not a class string or a component.
The selectors match ancestor `data-field-size` values and set the mapped font size.

## Part style functions

Each section lists every function and the class source it returns. A source such as `styles.root` names the component's internal CSS export.
A recipe call returns the generated class string for the selected variants.
