Part style functions return class-name strings, including an empty string for an unstyled part. They do not render elements or attach behavior, ARIA, state, or `data-*` attributes.
The styled parts already apply these functions. Use the functions directly only when you also own the markup and its state attributes.

The reference below follows the exports in `packages/kit/src/index.tsx` and `packages/kit/src/parts/`.

## Framework-neutral appearance helpers

Use `@codeui/styles` when you own the markup. A component entry exports an appearance helper for each part with variants. For example, `badgeStyleProps({ tone: "info" })` returns the badge class, part marker, and variant attributes. Use `dialogStyleProps.section({ variant: "well" })` for a dialog section, or call `dialogStyleProps({ size: "settings", chrome: "inset" })` for its panel.

Spread the result in Solid or Svelte, or pass it to Vue's `v-bind`. In React, map `class` to `className`. For DOM elements, import `applyStyleProps(element, props)` from `@codeui/styles`. The behavior adapter owns interaction state and sets `html[data-cui-input]` to `keyboard` or `pointer`.

The published `@codeui/styles/contract.json` includes the options, allowed values, and emitted defaults in `$appearance`. Each declared default renders the same with its attribute omitted. Set `data-cui-density` on a container to set the density of its subtree. See the [generated appearance reference](https://github.com/riccardoperra/codeui/tree/main/packages/styles#apply-appearance-props) for imports and part calls.

## `buttonStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose class names, variant helpers and CSS variable references.

`button()` returns the base class string. Set `data-size`, `data-variant`, or the `data-ghost` presence attribute on custom markup. `buttonIcon` and `buttonText` are class strings. `buttonVars` exposes the local CSS variables.

## `fieldStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose class names, variant helpers and CSS variable references.

`baseFieldVariants()` returns the base class. Set `data-size` and `data-variant` on the input. `FieldSizes` contains size names, `baseFieldTheme` is a class string, and `baseFieldVars`, `inputHeight`, and `fontSize` provide CSS variable references.

## `fieldErrorStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose class names, variant helpers and CSS variable references.

`errorMessage` is a class string for a field error. There are no callable recipes or variants.

## `fieldLabelStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose class names, variant helpers and CSS variable references.

`label` is a class string for a field label. There are no callable recipes or variants.

## `textFieldStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose class names, variant helpers and CSS variable references.

`baseFieldContainer` and `textField` are class strings. There are no callable recipes or variants.

## `dropdownMenuStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose class names, variant helpers and CSS variable references.

`content`, `subMenuContent`, `separator`, `item`, and `rightSlot` are class strings. `dropdownMenuThemeVars` is a variable contract. There are no callable recipes or variants.

## `popoverStyles`

Advanced raw namespace from `@codeui/kit`. These exports expose class names, variant helpers and CSS variable references.

The root namespace exports `content()` for the base classes. Use `data-variant="bordered"` for the bordered variant. The namespace also exposes the title and description classes and the `popoverThemeVars` variable contract.

## `styleFieldMessage`

Advanced helper from `@codeui/kit` for use inside a vanilla-extract style definition.
It accepts a complete map from each control size (`xs`, `sm`, `md`, `lg`) to a font size from `xs` through `xl`.
It returns a style object with `selectors`, not a class string or a component.
The selectors match ancestor `data-field-size` values and set the mapped font size.

## Part style functions

Each section lists every function and the class source it returns. A source such as `styles.root` names the component's internal CSS export.
Each helper returns a stable class string. Set the variant attributes described in the component page on your custom elements.
