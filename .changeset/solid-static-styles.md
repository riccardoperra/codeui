Extract Inkstone styles during the library build into a framework-neutral CSS package. Solid components automatically import their component CSS and theme without a vanilla-extract plugin. CSS-only applications can load all.css or the theme and individual component files. Existing kit class and token helpers reexport compiled modules. The styles package also supports HTML consumers without Solid.
