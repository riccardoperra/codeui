Build Inkstone styles from plain CSS and a Toghen-backed DTCG token resolver into a framework-neutral CSS package. Solid components automatically import their component CSS and theme without a vanilla-extract plugin. CSS-only applications can load all.css or the theme and individual component files. Existing kit class and token helpers reexport compiled modules. The styles package also supports HTML consumers without Solid.

Render open and force-mounted Dialog, Popover, Sheet and CommandMenu content on the server. Hydration adopts the existing nodes before moving them through Solid Portal, preserving event bubbling, custom autofocus, target changes and cleanup.
